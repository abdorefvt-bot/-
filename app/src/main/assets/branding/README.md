# Mishkat app icons

Upload the final logo artwork here after preparing it as a **PNG**.

## Required source image

- File name: `mishkat-logo.png`
- Format: PNG (not JPG), preferably transparent background.
- Canvas: square, 1024 × 1024 px.
- Logo: centered, with generous clear/safe space around it (keep the actual mark within the central 72% of the canvas).
- Use a clean high-resolution export; do not include a screenshot or mockup.

This one source artwork will be used to prepare:
1. The launcher/adaptive app icon, with the existing Mishkat burgundy background.
2. The Android notification small icon, converted to a clean single-color white silhouette with transparent background (Android requires a monochrome notification glyph).

Upload the PNG directly into this folder. Do not replace XML files manually.
